# Network Troubleshooting Labs

Hands-on troubleshooting scenarios built in Cisco Modeling Labs (CML). Each lab starts with a broken network. I document how I found each fault, why it happened, and how I fixed and verified it.

## Scenarios

| # | Scenario | Topics | Faults Found |

## How Each Lab Is Organized

- **README.md:** The full troubleshooting walkthrough with commands and screenshots
- **.yaml file:** Import it into CML to try the lab yourself
